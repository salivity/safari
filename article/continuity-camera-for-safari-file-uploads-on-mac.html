Continuity Camera for Safari File Uploads on Mac

Continuity Camera is an Apple ecosystem feature that bridges macOS and iOS, allowing you to use your iPhone’s camera to capture content directly onto your Mac. This article explains the underlying technology, system prerequisites, and the exact steps required to take a photo or scan a document with your iPhone and upload it directly into a file input field within the Safari web browser.

How the Integration Works

Websites use the HTML <input type="file"> element to let users upload files from their computer. Normally, interacting with this element opens a Finder window where you must select an existing file from your hard drive.

Safari bypasses the need for pre-existing local files by integrating directly with macOS system frameworks. When you trigger Continuity Camera on a file input field, the following happens behind the scenes:

  1. Device Discovery: Your Mac uses Bluetooth Low Energy (BLE) to detect your nearby iPhone and verify that both devices share the same Apple ID.
  2. Camera Activation: The Mac sends a wake signal to the iPhone, immediately launching a dedicated camera or document-scanning interface on the phone's screen.
  3. Data Transfer: Once you capture the image or scan, the iPhone transmits the data to the Mac over an encrypted, peer-to-peer Wi-Fi connection (Apple Wireless Direct Link).
  4. File Injection: Safari receives this data, automatically wraps it into a temporary file within the system cache, and binds it directly to the webpage's <input type="file"> element. The website treats this incoming data exactly as if you had selected a standard file from your hard drive.

Prerequisites

Before using this feature, ensure both your Mac and iPhone meet the following requirements:

  • Operating System: Your Mac must be running macOS Mojave (10.14) or later, and your iPhone must be running iOS 12 or later.
  • Apple ID: Both devices must be signed in to the exact same Apple ID using two-factor authentication.
  • Connectivity: Both Wi-Fi and Bluetooth must be turned on for both devices (they do not need to be connected to the same Wi-Fi network, just have the Wi-Fi radios enabled).
  • Settings: On your iPhone, go to Settings > General > AirPlay & Handoff (or Continuity Camera) and ensure the Continuity Camera toggle is turned on.

Step-by-Step Guide to Uploading in Safari

To bypass Finder and upload directly from your iPhone camera into a Safari web form, follow these steps:

  1. Open Safari on your Mac and navigate to the webpage containing the file upload field (often labeled as "Choose File" or "Browse").
  2. Instead of normal left-clicking, Control-click (or right-click) directly on the "Choose File" button.
  3. In the context menu that appears, look for your iPhone's name or the Import from iPhone or iPad submenu.
  4. Select either Take Photo or Scan Documents from the menu.
  5. Your iPhone will automatically open the camera interface:
    • If taking a photo: Frame your shot, tap the shutter button on your iPhone, and tap Use Photo.
    • If scanning a document: Point your iPhone at the document. It will automatically detect the edges and capture the scan. You can adjust the corners if necessary, scan additional pages, and then tap Save when finished.
  6. Look back at your Mac. The file input field in Safari will now display the name of your newly captured file, ready to be submitted with the rest of the web form.

Output Formats: Photos vs. Scans

Depending on which option you choose in the Safari context menu, macOS formats the temporary file differently to suit standard web upload requirements:

  • Take Photo: The captured image is converted and uploaded as a standard image file (typically a .jpg or .png, depending on what the specific web input accepts) named something generic like image.jpg.
  • Scan Documents: The iPhone applies perspective correction and contrast enhancement to make the document legible. It then compiles the scan—even if you scanned multiple pages in a single session—into a single, unified .pdf file and attaches it to the Safari file input.
