How to Export Safari Bookmarks to an HTML File

This article provides a straightforward guide on how to export your saved bookmarks from the Safari web browser into a standard HTML file. Whether you are creating a secure backup of your favorite websites or migrating your data to a different browser like Google Chrome, Mozilla Firefox, or Microsoft Edge, Safari's built-in export tool makes the process quick and effortless.

Exporting Bookmarks on a Mac

Safari on macOS includes a native feature that packages all of your bookmarks, including your Favorites bar and custom folders, into a universally compatible HTML document. Follow these steps to generate the file:

  1. Open Safari: Launch the Safari browser on your Mac.
  2. Access the File Menu: Click on File in the Apple menu bar at the very top-left corner of your screen.
  3. Select Export: Click on Export Bookmarks... from the dropdown menu. (In some macOS versions, you may need to hover over Export and then select Bookmarks).
  4. Name Your File: A save dialog box will appear. The file will automatically be named "Safari Bookmarks.html", though you can rename it to anything you prefer.
  5. Choose a Location: Select the folder where you want to store the file, such as your Desktop or Documents folder.
  6. Save the File: Click the Save button to complete the process.

Safari will instantly generate the HTML file in your chosen location. This single file contains your entire bookmark hierarchy.

Using Your Exported HTML File

Once you have the HTML file, you can use it immediately for backup or migration purposes:

  • For Backups: Move the "Safari Bookmarks.html" file to an external hard drive, a USB flash drive, or a cloud storage service. If you ever lose your data, you can restore your links in Safari by clicking File > Import From > Bookmarks HTML File... and selecting your saved document.
  • For Browser Migration: Every major web browser accepts HTML bookmark files. Simply open your new browser, navigate to its bookmark manager or settings menu, select the option to Import Bookmarks, and choose the HTML file you exported from Safari.

A Note for iPhone and iPad Users

The iOS and iPadOS versions of Safari do not have a direct button to export bookmarks to an HTML file. To export bookmarks from an iPhone or iPad, you must enable iCloud syncing for Safari on your mobile device (Settings > [Your Name] > iCloud > Show All > Safari). Once your bookmarks sync to a Mac signed into the same iCloud account, you can follow the macOS steps above to generate the HTML file.
