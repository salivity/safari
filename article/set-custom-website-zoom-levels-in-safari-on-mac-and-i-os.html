Set Custom Website Zoom Levels in Safari on Mac and iOS

This article provides a step-by-step guide on how to set and save a custom Page Zoom level for individual websites in the Safari web browser across both macOS and iOS devices. By adjusting these site-specific settings, Safari will automatically remember and apply your preferred page size every time you revisit that particular domain, eliminating the need to manually zoom in or out during future browsing sessions.

Setting Persistent Zoom on macOS

There are three ways to set a permanent zoom level for a specific website on a Mac. Safari remembers these adjustments automatically.

Method 1: Using the Keyboard Shortcut (Fastest)

  1. Open Safari and go to the website you want to adjust.
  2. Press Command (⌘) + Plus (+) to zoom in, or Command (⌘) + Minus (-) to zoom out.
  3. Leave the page at your desired zoom level. Safari will automatically save this exact setting for this specific domain.

Method 2: Using the Address Bar Menu

  1. Navigate to the desired website in Safari.
  2. Right-click (or Control-click) the website URL in the address bar.
  3. Select Settings for [Website Name]... from the dropdown menu.
  4. Locate the Page Zoom dropdown menu in the pop-up window.
  5. Select your preferred zoom percentage. The change will apply immediately and save automatically.

Method 3: Managing Multiple Websites via Safari Settings

  1. Open Safari and click Safari in the top-left menu bar.
  2. Select Settings... (or Preferences... on older macOS versions).
  3. Click on the Websites tab at the top of the window.
  4. Select Page Zoom from the left-hand sidebar.
  5. Under the "Configured Websites" or "Currently Open Websites" list, locate the website you want to change and select your desired zoom percentage from the dropdown menu next to its name.

Setting Persistent Zoom on iOS and iPadOS

On an iPhone or iPad, you cannot use the pinch-to-zoom gesture to save a persistent zoom level. Instead, you must use the address bar menu.

Adjusting the Zoom for a Specific Site

  1. Open the Safari app and go to the website you wish to modify.
  2. Tap the aA icon (or the Page Settings icon in newer iOS versions) located on the left side of the address bar.
  3. Tap the large A on the right side of the menu to increase the zoom level, or tap the small A on the left to decrease it.
  4. The number in the center will display the current zoom percentage (e.g., 115%, 125%).
  5. Tap anywhere outside the menu to close it. Safari will permanently remember this setting whenever you return to this website.

Resetting the Zoom Level on iOS

  1. Navigate back to the website.
  2. Tap the aA icon in the address bar.
  3. Tap directly on the percentage number in the middle (e.g., 125%) to instantly reset the website back to the default 100% zoom level.
