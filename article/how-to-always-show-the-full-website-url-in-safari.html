How to Always Show the Full Website URL in Safari

By default, the Safari web browser simplifies the Smart Search Field by only displaying the domain name of the website you are visiting rather than the full URL path. While this creates a minimalist interface, viewing the complete web address is essential for enhanced security, easier site navigation, and verifying the exact page you are viewing. This article explains the exact steps required to configure Safari on your Mac to always show the full website URL path.

To enable the full URL display in Safari on macOS, follow these steps:

  1. Open Safari: Launch the Safari web browser on your Mac.
  2. Access Settings: Click on Safari in the top-left corner of your screen in the menu bar. From the drop-down menu, select Settings... (or Preferences... if you are using macOS Monterey or an older version). You can also use the keyboard shortcut Command + , (comma) to open this menu directly.
  3. Go to the Advanced Tab: In the window that opens, click on the Advanced tab, which is located on the far right and is represented by a gear icon.
  4. Enable the Full URL: Look for the Smart Search field section at the very top of the pane. Check the box next to Show full website address.

The change takes effect immediately, and you can now close the Settings window.

Moving forward, Safari's Smart Search Field will continuously display the complete URL path—including the protocol, domain, and all specific page subdirectories—for every webpage you visit. If you ever wish to return to the default view that only shows the domain name, simply return to the Advanced tab and uncheck the box.
