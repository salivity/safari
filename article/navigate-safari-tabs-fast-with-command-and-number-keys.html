Navigate Safari Tabs Fast With Command and Number Keys

This article provides a quick guide on how to instantly switch between the first nine open tabs in the Safari web browser using the Command and number keys. You will learn the exact keyboard combinations required to jump to specific tabs, how the browser orders these tabs, and how to enable this shortcut in Safari's settings if it is not currently active.

Using the Keyboard Shortcut

To jump directly to one of your first nine open tabs in Safari, hold down the Command (⌘) key and press a number key from 1 to 9.

Safari assigns numbers to your open tabs sequentially from left to right:

  • Command + 1: Jumps to the first tab on the far left.
  • Command + 2: Jumps to the second tab from the left.
  • Command + 3: Jumps to the third tab from the left.
  • Command + 4 through 8: Jumps to the fourth through eighth tabs, respectively.
  • Command + 9: Jumps to the ninth tab from the left.

If you use Pinned Tabs in Safari, they are included in this count. For example, if you have two pinned tabs, pressing Command + 1 will take you to your first pinned tab, and pressing Command + 3 will take you to your first standard open tab.

How to Enable the Tab Switching Shortcut

If pressing Command and a number key opens a website from your Favorites bar instead of switching tabs, you need to adjust a setting in Safari. Follow these steps to enable tab switching:

  1. Open the Safari browser on your Mac.
  2. Click on Safari in the top menu bar (next to the Apple icon).
  3. Select Settings (or Preferences on older macOS versions) from the dropdown menu. You can also press Command + Comma (,) to open this menu directly.
  4. Click on the Tabs icon at the top of the settings window.
  5. Locate the checkbox labeled Use ⌘-1 through ⌘-9 to switch tabs.
  6. Check the box to enable the feature.

Once this box is checked, the keyboard shortcuts will immediately begin switching between your first nine open tabs rather than launching your bookmarked favorites.
