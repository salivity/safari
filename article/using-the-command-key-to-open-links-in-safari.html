Using the Command Key to Open Links in Safari

This article explains how holding down the Command key while clicking a link in the Safari web browser alters the way new tabs are opened. It covers the default behavior of this keyboard shortcut, how to use additional keys to modify the action on the fly, and how you can permanently customize this feature in Safari's settings to best fit your browsing workflow.

The Default Behavior

When you click a standard link in Safari, the new webpage usually loads right over the page you are currently viewing. However, if you hold down the Command (⌘) key and click the link, Safari intercepts this action and opens the webpage in a brand-new tab.

By default, Command-clicking opens the new tab in the background. This allows you to stay on your current page and continue reading or scrolling without interruption, while the new webpage loads quietly in the tab bar for you to view later.

Switching to the New Tab Immediately

If you want to open a link in a new tab and view it right away, you only need to add one more key to the shortcut.

Holding down both the Command (⌘) and Shift keys while clicking a link will open the webpage in a new tab and immediately make it the active tab. This brings the new page directly to the front of your screen, saving you the extra step of having to click on the new tab manually.

Customizing the Shortcut in Safari Settings

If you prefer that Command-clicking always takes you directly to the new tab without needing to press the Shift key, you can change Safari's default settings.

Follow these steps to change how new tabs open:

  1. Open the Safari browser on your Mac.
  2. Click on Safari in the top-left menu bar.
  3. Select Settings (or Preferences on older versions of macOS) from the drop-down menu.
  4. Click on the Tabs icon at the top of the settings window.
  5. Locate the checkbox labeled When a new tab or window opens, make it active.

If you check this box, the default behaviors will swap. Moving forward, holding the Command key and clicking a link will open the new tab and immediately switch your view to it. As a result, holding Command + Shift and clicking a link will now be the shortcut that sends the new tab to the background.
