Does Safari On-Device Translation Work Offline?

This article explains whether the Safari web browser can translate web content offline using downloaded language packs. You will learn how Apple's on-device translation functions without an internet connection, the exact System Settings required to enable it, and the practical differences between translating an entire webpage versus highlighted text while disconnected from the internet.

Yes, on-device translation in Safari works offline once the required language packs have been downloaded in System Settings. When configured properly, your Mac, iPhone, or iPad processes the translation locally using the device's neural engine rather than sending the webpage data to Apple's servers.

For offline translation to function in Safari, you must meet a few specific requirements before losing your internet connection:

  • Download Both Languages: You must download both the source language (the language of the webpage) and the target language (the language you are translating into). If you only download the foreign language pack and forget to download your native language pack, offline translation will fail.
  • Enable On-Device Mode: Downloading the packs is sometimes not enough; Safari will still attempt to reach Apple's servers by default for higher accuracy. You must explicitly enable "On-Device Mode" in your settings to force the system to use local files exclusively.
  • Pre-load the Webpage: Because you are offline, the webpage you want to translate must already be open in a Safari tab, cached, or saved ahead of time in your offline Reading List.

To set this up on a Mac, open System Settings, click General, and select Language & Region. Scroll to the bottom, click Translation Languages, download both required languages, and check the box for On-Device Mode. On an iPhone or iPad, open Settings, navigate to Translate (or Apps > Translate), tap Downloaded Languages to get your required packs, and toggle on On-Device Mode.

While offline, there are two ways to trigger the translation in Safari, and one is more reliable than the other:

  1. Selected Text Translation (Most Reliable): Highlight the text you want to read on the webpage, right-click (on Mac) or tap (on iOS) the highlighted area, and select Translate from the menu. A system pop-up box will immediately translate the text using your downloaded language packs. This method works offline every time.
  2. Full-Page Translation: Clicking the translate icon in the Safari address bar to convert the entire webpage layout at once can be inconsistent when completely offline. Safari occasionally requires a brief server handshake to initialize the full-page translation script, even with On-Device Mode enabled. If the address bar icon states that translation is unavailable while you are offline, use the selected text method above as a guaranteed workaround.
