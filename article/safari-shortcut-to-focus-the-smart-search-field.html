Safari Shortcut to Focus the Smart Search Field

This article provides a quick guide on the keyboard shortcut used to instantly focus and highlight the Smart Search Field in the Safari web browser. You will learn the exact key combination required to immediately begin typing a URL or search query without needing to use your mouse or trackpad, along with how this function streamlines your daily browsing experience.

To focus and highlight the Smart Search Field in Safari, press Command + L (⌘ + L) on your keyboard.

When you use this shortcut, Safari immediately moves your cursor to the address bar at the top of the browser window and selects the entire current web address. Because the existing text is automatically highlighted, you do not need to press the Delete key before typing. The moment you start typing a new website address or a search term, your new input will instantly replace the highlighted URL.

Here is the step-by-step process to use the shortcut effectively:

  1. Ensure that Safari is your active application window.
  2. Press and hold the Command (⌘) key on your keyboard.
  3. Tap the L key, then release both keys.
  4. Type your desired search query or web address.
  5. Press the Return key to execute the search or navigate to the website.

This keyboard shortcut works identically on macOS and on iPadOS when an external hardware keyboard is connected to an iPad. In addition to typing a new search, pressing Command + L is also the fastest way to grab the current webpage's address. Once the Smart Search Field is highlighted using the shortcut, you can immediately press Command + C to copy the URL to your clipboard without ever touching your mouse.
