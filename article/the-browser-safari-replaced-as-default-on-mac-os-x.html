The Browser Safari Replaced as Default on Mac OS X

This article explains the history behind the default web browser on Apple's Mac OS X, specifically detailing how the Safari web browser replaced Microsoft's Internet Explorer for Mac. It covers the historic 1997 agreement between Apple and Microsoft that initially placed Internet Explorer on every Macintosh computer, Apple's secret development of its own browser engine, and the 2003 launch of Safari that permanently changed the Mac software ecosystem.

The web browser that Safari replaced as the default on Mac OS X was Microsoft's Internet Explorer for Mac.

To understand why a Microsoft product was the default browser on Apple computers, you have to look back to August 1997. At the time, Apple was struggling financially. Recently returned CEO Steve Jobs announced a historic five-year partnership with Microsoft. As part of this agreement, Microsoft invested $150 million in Apple and promised to continue developing Microsoft Office for the Mac. In return, Apple agreed to bundle Internet Explorer with the Mac OS and make it the default web browser, effectively sidelining Netscape Navigator.

For the next five years, Internet Explorer was the standard gateway to the web for Mac users. It shipped as the default browser on Mac OS 8.1 through Mac OS 9, and carried over into the early versions of Mac OS X, including OS X 10.0 (Cheetah), 10.1 (Puma), and 10.2 (Jaguar).

However, as the five-year agreement neared its expiration in 2002, Apple grew dissatisfied with the arrangement. Development on Internet Explorer for Mac had slowed down significantly, and its performance was lagging behind the Windows version. Furthermore, Apple wanted complete control over the user experience on its new Mac OS X operating system rather than relying on a primary competitor for something as crucial as internet access.

Apple quietly hired a team of developers to build a new browser from the ground up. They chose an open-source HTML rendering engine called KHTML (from the Linux KDE project) as their foundation, which Apple modified and rebranded as WebKit.

On January 7, 2003, at the Macworld Expo in San Francisco, Steve Jobs officially unveiled the Safari web browser. Jobs touted its blinding speed—claiming it was three times faster than Internet Explorer for Mac—and its clean, minimalist interface.

Safari was initially released as a public beta for Mac OS X 10.2 (Jaguar) on that same day. Just a few months later, in June 2003, Microsoft announced that it was halting all further development on Internet Explorer for Mac, acknowledging that Apple was in a better position to build a browser integrated with its own operating system.

In October 2003, Apple released Mac OS X 10.3 (Panther). With this release, Safari was officially installed as the default web browser, permanently replacing Internet Explorer for Mac.
