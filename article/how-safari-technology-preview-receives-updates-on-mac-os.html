How Safari Technology Preview Receives Updates on macOS

Yes, Safari Technology Preview receives updates directly through the standard macOS System Settings Software Update mechanism. This article explains how the update process works for Apple's experimental browser, covering the initial installation requirement, the exact steps to download subsequent updates via System Settings, and how the browser maintains its update cycle alongside the standard version of Safari.

The Initial Installation

Before you can receive automatic updates through macOS, you must first manually download and install Safari Technology Preview from the Apple Developer website. Unlike the standard Safari browser, the Technology Preview does not come pre-installed on a Mac. Once you run the initial installer package and the application is placed in your Applications folder, it registers itself with the macOS update server.

Receiving Updates via System Settings

After the initial installation is complete, you never need to download the standalone installer again. Apple delivers all future releases directly through the native operating system update tool.

To check for and install Safari Technology Preview updates on macOS Ventura or later:

  1. Open System Settings on your Mac.
  2. Click on General in the sidebar.
  3. Select Software Update.
  4. Wait for macOS to check for updates.

If a new version of Safari Technology Preview is available, it will appear here alongside standard macOS updates. Often, you will need to click "More Info..." under the "Other updates are available" section to see the specific Safari Technology Preview update and select it for installation.

For users on macOS Monterey or earlier, the process is nearly identical, except it is located by opening System Preferences and clicking directly on Software Update.

Automatic Updates and Release Cadence

Because Safari Technology Preview utilizes the built-in macOS Software Update mechanism, it also respects your automatic update preferences. If you have "Install application updates from the App Store" or "Install system data files and security updates" enabled in your Software Update settings, the browser will often update itself in the background.

However, because the browser cannot update while it is actively running, you will receive a standard macOS notification prompting you to quit and restart the browser to finish applying the update. You can expect to see these updates appear in System Settings roughly every two weeks, as Apple uses this rapid release cycle to test the latest layout technologies, visual effects, and developer tools.

Impact on Standard Safari

Updating Safari Technology Preview through System Settings only affects the preview application. Because it is a completely standalone application with its own preferences and cache, installing its updates will not alter, overwrite, or force a restart of your standard Safari browser or the macOS operating system itself.
