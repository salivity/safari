How to Manually Trigger Safari Password Suggestions

This article explains how to manually force the Safari web browser to display its password suggestion and AutoFill popover when a website's registration or login form fails to trigger it automatically. By using built-in context menus, keyboard shortcuts, and system workarounds on both Mac and iOS devices, you can easily generate strong passwords or access saved credentials on uncooperative websites.

Click the Hidden Key Icon

Sometimes Safari recognizes a password field, but the webpage's scripts prevent the suggestion bubble from popping up automatically.

  1. Click or tap directly inside the password text box.
  2. Look at the far-right edge of the input field for a small Key icon.
  3. Click or tap this icon to manually force the password suggestion popover to appear.

Force the Popover on Mac Using the Context Menu

If the key icon is completely missing on macOS, you can bypass the website's form restrictions using the right-click menu.

  1. Move your cursor inside the blank password input field.
  2. Right-click (or hold the Control key and click) the field.
  3. Hover your cursor over AutoFill in the context menu.
  4. Click Passwords... from the submenu.
  5. Authenticate with Touch ID or your Mac password to view your saved credentials or select a suggestion.

Force the Popover on iPhone and iPad

On iOS and iPadOS, poorly coded web forms often stop Safari from highlighting the password field in yellow and offering a strong password. You can manually trigger the prompt using two different methods.

Method 1: Use the QuickType Keyboard Bar

  1. Tap inside the password field so the on-screen keyboard appears.
  2. Look at the gray bar directly above the keyboard letters.
  3. Tap Passwords or the Key icon.
  4. Select Suggest New Password from the menu, or choose an existing login from your list.

Method 2: Use the Long-Press Action Menu

  1. Tap and hold your finger inside the empty password text box for a second, then release.
  2. A small action menu (containing Copy, Paste, etc.) will appear above the field.
  3. Tap AutoFill (if you do not see it immediately, tap the right arrow icon on the edge of the menu).
  4. Tap Passwords to open the credential selector.

Workaround for Generating New Passwords

If a website's code completely disguises the password field as a standard text box, Safari will only allow you to paste existing passwords using the methods above and will refuse to show the "Suggest Strong Password" option. To force Safari to generate a new password in this scenario, create the credential manually first.

On Mac:

  1. Click Safari in the top menu bar and select Settings (or Preferences).
  2. Click the Passwords tab and unlock it using Touch ID or your system password.
  3. Click the + (Add) button at the top of the password list.
  4. Enter the website's address and your username.
  5. Click the Password field in this window—Safari will immediately trigger the strong password suggestion popover here.
  6. Click Add Password, then right-click the newly created entry to copy the password and paste it into the website form.

On iPhone and iPad:

  1. Open the Settings app and tap Passwords (or open the standalone Passwords app on iOS 18 and later).
  2. Unlock the screen with Face ID, Touch ID, or your passcode.
  3. Tap the + (Add) button at the bottom right corner.
  4. Type the website's domain name and your username.
  5. Tap the Password field. The system will automatically generate and insert a strong password suggestion.
  6. Tap Done in the top right corner, copy the newly generated password, and paste it into the Safari web form.
