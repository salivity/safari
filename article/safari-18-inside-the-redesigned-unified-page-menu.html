Safari 18: Inside the Redesigned Unified Page Menu

This article provides an overview of how Safari 18 redesigned the unified Page Menu in the address bar to create a more streamlined browsing experience. It details how Apple replaced the legacy format menu to consolidate essential tools—specifically Reader mode, Translation, Distraction Control, and web extensions—into a single, context-aware hub that reduces clutter and improves accessibility.

The New Address Bar Icon

In Safari 18, Apple replaced the traditional "aA" icon on the left side of the address bar with a new Page Menu icon, represented by a rectangle with two horizontal lines beneath it. Clicking or tapping this icon opens a redesigned, card-style popover menu. Instead of showing a static list of text options, the new Page Menu dynamically prioritizes tools based on the webpage you are currently viewing.

Streamlined Access to Reader Mode

Reader mode is no longer just a toggle hidden in a list; it is now a prominent, pill-shaped button located at the very top of the Page Menu. When a webpage supports Reader view, the button becomes active. Tapping it immediately strips away page clutter, and in Safari 18, this menu integration also provides quick access to a newly added Table of Contents and article summaries on supported devices.

Dynamic Webpage Translation

Rather than occupying permanent space when it is not needed, the Translation tool now surfaces dynamically within the Page Menu. When Safari detects a webpage in a language different from your system default, the Page Menu icon in the address bar briefly animates into a translation symbol. Opening the Page Menu reveals the "Translate to [Language]" option right at the top, next to the Reader button, allowing for instant conversion without digging through sub-menus.

Introducing Distraction Control

Safari 18 introduces Distraction Control, and Apple placed its trigger directly into the primary section of the Page Menu, labeled as "Hide Distracting Items." Selecting this option closes the menu and turns the webpage into an interactive canvas. Users can then click or tap on annoying static elements—such as newsletter sign-up overlays, cookie consent banners, or floating video players—to dissolve them from view. If you want to bring those elements back, you simply return to the Page Menu and select "Show Hidden Items."

Centralized Web Extensions

Previously, managing web extensions required navigating a cluttered toolbar on Mac or scrolling through awkward menus on iOS. The redesigned Page Menu dedicates a specific middle section to installed and active extensions. Users can see which extensions have access to the current webpage, toggle them on or off, and launch extension-specific interfaces directly from this unified list. A "Manage Extensions" button is also included to quickly adjust permissions.

Decluttering Secondary Settings

To ensure Reader, Translation, Distraction Control, and extensions remain the focal point, Safari 18 pushed less frequently used settings to the bottom of the Page Menu. Page zoom controls are condensed into compact "-" and "+" buttons, while advanced configurations like "Request Desktop Website," "Auto-Lock," and site-specific privacy settings are now neatly tucked away behind a three-dot "More" button in the bottom corner of the menu.
