Safari Tab Highlighting and Keyboard Focus Navigation

Enabling the "Press Tab to highlight each item on a webpage" setting in the Safari web browser fundamentally alters how users interact with web content using a keyboard. By default, Safari restricts the Tab key to navigating only between text fields and pop-up menus. This article explains how turning on this specific accessibility setting expands keyboard focus to include all interactive elements, specifically links and buttons, bringing Safari in line with standard navigation behaviors found in other major web browsers.

Default Safari Keyboard Navigation

Out of the box, Safari limits keyboard focus to form inputs. When you press the Tab key on a webpage with the default settings, the focus ring skips over hyperlinks, navigation menus, and interactive buttons. Instead, it only jumps from one text box to the next.

Under this default configuration, if you want to highlight links and buttons, you are forced to use the keyboard shortcut Option + Tab. This requires pressing two keys simultaneously for every single step of navigation, which slows down browsing for keyboard-reliant users and developers testing web accessibility.

What Changes When the Setting is Enabled

When you turn on "Press Tab to highlight each item on a webpage," the behavior of the Tab and Option + Tab shortcuts is inverted:

  • The Tab Key: Pressing Tab alone now moves the keyboard focus sequentially through every focusable element on the page. This includes text inputs, checkboxes, buttons, and all hypertext links.
  • Shift + Tab: Pressing Shift + Tab moves the focus backward through these same links, buttons, and inputs.
  • Option + Tab: Pressing Option + Tab now reverts to the restricted mode, skipping links and buttons to highlight only form fields and pop-up menus.

Impact on Links and Buttons

With this setting active, links and buttons become first-class citizens in keyboard navigation. As you press the Tab key, Safari draws a visible focus indicator (typically a blue outline) around each link and button as you land on it.

Once a link or button is highlighted, you can interact with it directly from the keyboard:

  • Activating Links: When a link is highlighted, pressing the Return (or Enter) key will follow the URL, acting just like a mouse click.
  • Activating Buttons: When a button is highlighted, pressing either the Space bar or the Return key will trigger the button's action, such as submitting a form or opening a modal window.

How to Enable the Setting

To change this behavior and allow the Tab key to focus on links and buttons, follow these steps in Safari on macOS:

  1. Open the Safari menu in the top-left corner of your screen.
  2. Select Settings (or Preferences on older macOS versions).
  3. Click on the Advanced tab on the far right.
  4. Next to the Accessibility label, check the box for Press Tab to highlight each item on a webpage.

The change takes effect immediately, allowing you to seamlessly navigate across all webpage links and buttons using just the Tab key.
