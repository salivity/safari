When Apple Added Web Push Notifications to iOS and iPadOS

This article provides a concise history and breakdown of when Apple introduced Web Push notifications for Safari web apps on iOS and iPadOS. It covers the exact release date, the specific software update that enabled the feature, and the operational requirements that users and developers must meet to utilize push notifications for Home Screen web applications.

Apple officially introduced support for Web Push notifications on March 27, 2023, with the public release of iOS 16.4 and iPadOS 16.4. Although Apple originally announced the feature during its Worldwide Developers Conference (WWDC) in June 2022 as part of the broader iOS 16 reveal, the functionality was held back until the 16.4 point release in the spring of the following year.

To use Web Push notifications on an iPhone or iPad, users cannot simply opt into notifications directly from a standard Safari browser tab. Apple requires the user to first save the website as a Progressive Web App (PWA) to their device's Home Screen. This is done by tapping the Share button in Safari and selecting the "Add to Home Screen" option.

Once the web app is saved and launched directly from the Home Screen, it can request permission to send notifications. To prevent spam, Apple requires a direct user gesture—such as tapping a "Subscribe" or "Enable Notifications" button within the web app—before the native iOS permission prompt will appear.

When permission is granted, the web app's notifications function identically to those from native apps downloaded via the Apple App Store. The notifications appear on the Lock Screen, in the Notification Center, and on paired Apple Watches. They also support app icon badges on the Home Screen and respect the user's configured Focus modes.

For developers, Apple implemented this feature using established W3C web standards, specifically the Push API, the Notifications API, and Service Workers. This standards-based approach meant that developers who had already built Web Push systems for desktop browsers or Android devices could easily extend support to iOS and iPadOS without having to join the Apple Developer Program or rewrite their core notification architecture.
